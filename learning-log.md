# Learning log

Small projects, useful lessons and steady coding practice.

**Planned start: 22 October 2026**

## Daily routine

Aim for 45 to 60 minutes when possible.

1. Pick one small goal.
2. Write or improve some code.
3. Run it and check a normal case and an edge case.
4. Commit a meaningful change.
5. Add a short entry below with a link to the work.

A useful entry explains what I learned or fixed. If I miss a day, I pick up from the next small goal.
